# Aurora SDG search queries, version 5.0

The 17 files `query_SDG1.xml` … `query_SDG17.xml` are copied unchanged from
https://github.com/Aurora-Network-Global/sdg-queries at commit
`9acd03d00b6c54cede19f5eb0b45eec193e5724b` (2023-02-17), the version 5.0 queries
(Vanderfeesten et al., Zenodo, doi:10.5281/zenodo.3817443) that assign the Aurora
labels used in this repository. They are licensed under CC BY 4.0 (`LICENSE.md`).

Notebook `04_revision_analyses.ipynb`, part C, uses the quoted terms of these
queries to remove Aurora's query vocabulary from the texts (query-vocabulary
ablation).
